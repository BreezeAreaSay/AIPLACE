# Triad Canvas — чат с друзьями, который ведёт за тебя Anytype

Групповой чат с тремя живыми ИИ-персонажами (характеры, желания, память, отношения, страх смерти) — и типизированная
библиотека объектов в духе Anytype (Люди, Проекты, Задачи, Идеи, Книги, Закладки…), которую **никто не заполняет
руками**: Архивариус вытаскивает объекты, свойства, связи и упоминания из разговора, а друзья ею пользуются —
отвечают на «что у меня по Ивану?» точными фактами, а не догадками.
Три радикально разных ИИ-субъекта с HP, дофамином, уважением к игроку и **скрытыми целями, которые на лету
выдумывает LLM-Режиссёр** — никаких захардкоженных повесток в коде.

| Агент | id | Профиль | Цвет узлов |
|---|---|---|---|
| Аркадий Борисович | `physicist` | физик-ядерщик на пенсии, детерминист, энтропия и КПД | `#00F0FF` |
| Софья Генриховна | `lit_teacher` | преподаватель русской классики, достоевщина, обломовщина | `#FF0055` |
| Кэп («Кислота») | `graffiti` | граффити-бомбер, анархист, взлом правил | `#CCFF00` |

## Dual-Target архитектура (локально сегодня → Telegram Mini Apps завтра)

```
frontend/  (Vite + React + TS + Tailwind + Mermaid)   ──HTTP /api/* + SSE──▶   backend/  (Rust + Axum + SQLite)
            mobile-first «стакан» max-w-md                                     ├─ director.rs   LLM-Режиссёр (JSON)
            + десктопный инспектор                                             ├─ agent_runner  prefill <ego_thought>
                                                                               ├─ mermaid.rs    живая блок-схема
                                                                               └─ openrouter.rs OpenRouter client
```

* Фронтенд **никогда** не трогает OS-API: только `fetch('/api/…')` и `EventSource('/api/events')`.
  Тот же бандл открывается в браузере, в Tauri-обёртке и в WebView Telegram.
* Бэкенд — один бинарник. На ноутбуке слушает `localhost:3000`; на VPS за $5 — тот же бинарник, тот же SQLite,
  плюс он сам отдаёт встроенный UI. Telegram Mini App просто указывает на его URL, а сервер по `initData`
  раскладывает пользователей по отдельным комнатам.

## Десктоп-приложение (Tauri)

Нативное окно + иконка в трее, внутри — тот же Rust-сервер на `127.0.0.1:<свободный порт>` и тот же UI.
Наружу ничего не торчит; данные в `~/.triad` общие с CLI-версией, так что комната переезжает без потерь.
Закрытие окна сворачивает в трей (комната продолжает жить), выход — из меню трея; там же «🎲 Автономный тик».

Сборка у себя (Windows: нужны Rust + Node + C++ Build Tools, WebView2 уже есть в Windows 10/11):

```powershell
cd desktop; npm install; npm run build
```

Инсталлятор: `desktop\src-tauri\target\release\bundle\nsis\Triad Canvas_<ver>_x64-setup.exe` (и `.msi` рядом).
Для разработки — `npm run dev` в `desktop/` (перед этим один раз `npm run build` в `frontend/`, UI встраивается в сервер).
`.github/workflows/desktop.yml` собирает инсталляторы под Windows/macOS/Linux и прикладывает к релизу.

## Установка за минуту (готовый бинарник)

Один файл `triad` со встроенным UI, без Node/Rust на машине:

```bash
curl -fsSL https://raw.githubusercontent.com/BreezeAreaSay/AIPLACE/main/install.sh | sh
```

```powershell
irm https://raw.githubusercontent.com/BreezeAreaSay/AIPLACE/main/install.ps1 | iex
```

Установщик кладёт бинарник в `~/.triad/bin` (Windows: `%LOCALAPPDATA%\triad\bin`), добавляет его в PATH и сразу
запускает мастер `triad setup`, где ты вставляешь ключ OpenRouter. Дальше:

| Команда | Что делает |
|---|---|
| `triad` | запустить комнату → http://localhost:3000 (без ключа спросит его прямо в терминале) |
| `triad setup` | мастер: ключ, модель агентов, модель Режиссёра, порт → `~/.triad/config.env` |
| `triad key sk-or-v1-…` | записать ключ без мастера (`triad key` без аргумента — удалить) |
| `triad config` | где лежит конфиг и что в нём (ключ маскируется) |
| `triad update` | обновиться до последнего GitHub Release (`--check` — только проверить) |
| `triad --port 8080` | любой флаг/переменная из таблицы ниже |

Ключ можно вставить и **в UI** (⚙ в шапке или баннер «mock-режим»): он уходит в `~/.triad/config.env`, в браузер
никогда не возвращается, а менять его через UI разрешено только с той машины, где крутится сервер
(иначе на VPS любой открывший Mini App мог бы подменить ключ). Снять ограничение: `ALLOW_REMOTE_SETTINGS=true`.

При старте `triad` тихо проверяет GitHub Releases и показывает бейдж «доступна vX.Y.Z» в шапке UI
(отключить: `TRIAD_NO_UPDATE_CHECK=1`). База и конфиг живут в `~/.triad` (переопределить: `TRIAD_HOME`).

## Релизы (для мейнтейнера)

```bash
# 1. поднять version в backend/Cargo.toml (и Cargo.lock: cd backend && cargo update -p triad-canvas-backend)
# 2. закоммитить, затем:
git tag v0.2.0 && git push origin v0.2.0
```

`.github/workflows/release.yml` соберёт UI, встроит его в бинарники для Linux x64/arm64, macOS Intel/Apple Silicon
и Windows x64, и опубликует GitHub Release с `SHA256SUMS.txt`. Тег обязан совпадать с версией в `Cargo.toml`
(workflow падает иначе). Имена ассетов `triad-<ver>-<target>.tar.gz|zip` — их ждут `install.sh` и `triad update`.
CI (`ci.yml`) на каждый push гоняет `npm run build`, `cargo clippy -D warnings` и `cargo test`.

## Комната живёт без тебя

- **Пульс** (`HEARTBEAT_MINUTES`, по умолчанию 40): когда ты молчишь дольше, в комнате что-то происходит само —
  кто-то пишет тебе первым (про дело из библиотеки, открытое слово или незакрытую тему), двое заводят разговор
  между собой, кто-то рассказывает о **своём проекте** (у каждого жителя он есть в библиотеке: осциллограф
  Аркадия, «Котлован» Софьи, стена Кэпа). Интервал удваивается, пока тебя нет (до суток), в `QUIET_HOURS` тишина.
- **Пока тебя не было**: разделитель и счётчик непрочитанного в чате и в заголовке окна; десктоп показывает
  системное уведомление, когда окно свёрнуто; Telegram-комнаты получают пуш от бота с кнопкой «Открыть».
- **Стриминг**: реплика появляется по словам («печатает…»), не блоком после паузы.
- **Ссылки**: кинь URL в чат — страница читается, сжимается в выжимку, становится объектом «Закладка» с
  `url / источник / выжимка`, а друзья обсуждают содержимое, а не ссылку.
- **Устойчивость**: ретраи с бэкоффом на 429/5xx (free-tier модели режут по частоте), дневной бюджет вызовов
  (`DAILY_CALL_BUDGET`), счётчик в шапке и `/api/health`.

## Библиотека (Anytype на стероидах)

- **Типы** со схемами свойств, как в Anytype: Страница, Заметка, Задача (готово, срок, приоритет, статус,
  исполнитель → Человек), Проект (статус, срок), Человек (роль, компания, контакт, кто мне), Закладка (url,
  источник, выжимка), Идея (статус), Цель (прогресс, срок, статус), Книга, Фильм, Рецепт, Запись дневника.
  Новые типы Архивариус заводит сам (не больше одного за раунд, помечены `new`), можно завести и вручную.
- **Архивариус** — субагент после каждого раунда: 0–4 объекта с типом и свойствами (дедуп против существующих),
  связи с видом (`belongs_to`, `about`, `blocks`, `assigned_to`, `contradicts`…), **упоминания** для каждого
  сообщения — это обратные ссылки: на странице объекта видно все реплики, где он всплывал.
- **Запросы к памяти.** Reader распознаёт «что я обещал Ивану / что у меня по проекту / какие книги хотел»,
  код делает поиск по библиотеке и отдаёт говорящим «справку» — друзья отвечают фактами.
- **Чипы в чате**: объекты, связанные с сообщением, показаны под ним; клик открывает страницу объекта.
- **Страница объекта**: тип (меняется), свойства по схеме (форма), тело в markdown, пометки друзей, связи с
  видом, «где всплывало», архив, кнопки «обсудить / развить / оспорить».
- **Экспорт/импорт** в Markdown (см. ниже «Заметки и Markdown»); поиск `GET /api/search?q=&type=`.

## Заметки и Markdown

Каждый объект — это markdown-заметка с типом и свойствами. Всё, что ты, агенты и внешние клиенты пишут,
хранится как `.md`-текст, и наоборот: папка `.md` ложится в библиотеку как есть.

- **Редактор** на странице объекта: панель (жирный, курсив, заголовок, списки, чеклист, цитата, код, ссылка,
  `[[вики-ссылка]]`), продолжение списков по Enter, Tab-отступ, автосохранение через секунду после ввода,
  `Ctrl+Enter` — показать, двойной клик по тексту — редактировать. Заголовок правится прямо на месте.
- **`[[Название]]`** — ссылка на объект библиотеки (автодополнение по `[[`). В просмотре это чип с иконкой
  типа; клик открывает объект, несуществующий — предлагает создать заметку. Работает в заметках, пометках и
  в чате.
- **GFM**: таблицы, чеклисты (галочки кликабельны прямо в просмотре и меняют текст), зачёркивание, код,
  автоссылки. Реплики в чате тоже рендерятся как markdown.
- **Импорт**: перетащи `.md`/`.txt`-файлы (или папку Obsidian) на библиотеку, либо кнопка «импорт».
  Frontmatter `type:` задаёт тип (id или название), известные ключи становятся свойствами, `# Заголовок` или
  имя файла — названием, `[[ссылки]]` между заметками — связями.
- **Экспорт**: одна заметка — кнопка «скачать .md» (frontmatter + тело + пометки + связи как `[[…]]`),
  вся библиотека — `GET /api/export.md`. «Скопировать как markdown» — в буфер.
- **Агенты пишут в заметки**: инструмент `library_append` дописывает абзац или запись под `## Заголовок`,
  не стирая написанное (лог проекта, дневник, развитие твоей идеи). Чип `✍ дописал в «…»` под репликой.
- **Слэш-команды в композере** (начни с `/`): `/заметка`, `/задача`, `/идея`, `/человек`, `/цель`,
  `/дневник` — сохранить в библиотеку молча (первая строка — заголовок, остальное — тело); `/найти слова` —
  поиск; `/спор` — пусть поспорят сами. Кнопка 🔖 рядом с «отправить» — то же, что `/заметка`.

## Двор: состав по ролям

Трое — это стартовый пресет, а не потолок. Кнопка «двор» в полоске персонажей (или 👥 в шапке) открывает
состав: до восьми жителей.

- **Позвать по роли.** 13 пресетов с готовым характером, именем, скрытой целью и личным проектом в библиотеке:
  Скептик-физик, Литератор, Хулиган-визионер, Наставник, Психолог, Продюсер, Критик, Летописец, Мечтатель,
  Делец, Тренер, Инженер, Бабушка у подъезда. Любое поле правится перед приглашением; можно описать своего
  персонажа с нуля (имя, строка «кто это», характер во втором лице, цвет, знак).
- **У каждого своя модель и голос.** Персонажу можно назначить модель из каталога OpenRouter (пусто — общая)
  и голос TTS. Сильная модель на одного «мозга» двора и бесплатные на остальных — нормальная схема.
- **Настроить потом.** Характер, имя, цель, модель и голос меняются в любой момент; HP, дофамин, дневник и
  история остаются. Мёртвого можно вернуть к жизни.
- **Уехать и вернуться.** «Уехать» — персонаж перестаёт говорить, но его реплики, память и объекты остаются;
  из «в отъезде» он возвращается одной кнопкой. Двор не может остаться пустым.
- Новый житель получает нейтральные отношения со всеми, системное сообщение в чате и свой проект; Режиссёр,
  Психолог, пульс и отношения работают с любым составом (граф отношений строится по кругу).

API: `GET /api/roles`, `POST /api/agents` `{role?, name?, archetype?, system_core?, color?, glyph?, model?, voice?, agenda?}`,
`PATCH /api/agents/{id}` (те же поля + `active`, `revive`), `DELETE /api/agents/{id}` = уехать.

## Файлы, типы и окна наружу

**Файлы.** На объект можно бросить что угодно: картинки, PDF, тексты, CSV, JSON, HTML (кнопка «+ файл» или
перетаскивание на страницу объекта; скрепка в композере и вставка из буфера делают из файлов новые объекты
«Файл»/«Картинка» и вставляют `[[ссылки]]` в сообщение; в библиотеку можно сбросить целую папку: `.md` станут
заметками, остальное — объектами). Картинки — в галерее с просмотром на весь экран. Из PDF и текстов
извлекается текст: его видят агенты (`library_get` → вложения, `file_read` кусками, `library_search` ищет и
по тексту файлов), а в разговоре об объекте выдержка попадает прямо в промпт. Хранится в `~/.triad/files/<комната>/`.

**Типы — конструктор.** Кнопка «ползунки» в библиотеке (или двойной клик по типу): название, иконка, цвет,
**шаблон заметки** (новые объекты типа начинаются с него) и поля. Виды полей: текст, длинный текст, число,
**рейтинг ★** (1–N), галочка, дата, дата-время, выбор, мультивыбор, теги, ссылка, картинка-url, email,
телефон, объект (связь на тип). Встроенные типы тоже редактируются; новые встроенные поля добавляются к
старым комнатам без потери твоих. Агенты получают схему через `library_types` и заполняют поля при
`library_create`/`library_update` (в том числе ставят оценки).

**Окна наружу** (⚙ → «окна наружу»; все необязательны, включаются по ключу или без него):

| Что | Как включить | Что даёт |
|---|---|---|
| Поиск в сети | по умолчанию `ddg` без ключа; `SEARCH_PROVIDER=tavily\|brave\|searxng` + ключ/URL | инструменты `web_search`, `web_fetch`; в tags-режиме агент пишет `ИЩУ В СЕТИ: …` на стадии мысли и получает результаты перед репликой |
| Погода | `WEATHER_CITY=Москва` (Open-Meteo, без ключа) | строка «за окном» в шапке чата, у Режиссёра и агентов; `weather_now` |
| Календарь | подписка на `GET /api/calendar.ics` (сроки задач, события, слово, дни рождения) и/или `CALENDAR_ICS_URL` твоего календаря | Режиссёр видит ближайшие события; `calendar_upcoming` |
| Справочники | книги — OpenLibrary, Википедия — без ключа; фильмы — `TMDB_API_KEY` | кнопка «подтянуть данные» на странице книги/фильма/человека/места заполняет пустые поля и дописывает описание; `lookup` |
| Ленты | объект типа «Лента» с URL RSS/Atom; `FEEDS_EVERY_MIN` (180) | новые записи становятся закладками с выжимкой; когда ты молчишь, кто-то приносит новость в чат (пульс `news`); `feed_fetch` |
| GitHub | свойство `repo` у проекта; `GITHUB_TOKEN` не обязателен | кнопка «GitHub» дописывает коммиты и issues в раздел проекта; `github_activity` |
| Голос | без ключей — голоса браузера (🔊 у реплики, 🎙 в композере через распознавание браузера); `TTS_URL/TTS_API_KEY/TTS_MODEL/TTS_VOICES`, `STT_URL/STT_API_KEY/STT_MODEL` — OpenAI-совместимые | озвучка реплик голосом персонажа, диктовка через Whisper (Groq бесплатно) |

## Агенты чувствуют систему как MCP

Библиотека для агентов — не текст в промпте, а **набор инструментов** в формате MCP (Model Context Protocol).
Один и тот же реестр (`backend/src/tools.rs`) отдаётся трём потребителям:

| Кто | Как |
|---|---|
| Агенты комнаты | `AGENT_TOOLS=native` — реплика идёт через function calling: модель сама вызывает `library_search`, `library_create`… до 4 раундов, потом говорит. `tags` — те же действия тегами `<act>{"op":…}</act>` в тексте (для моделей без tools). `auto` смотрит в каталог OpenRouter. |
| Ты в UI | каждое действие агента становится чипом под его репликой: «завёл задачу», «закрыл», «связал», «запись в …» |
| Внешние клиенты | `POST /mcp` — JSON-RPC 2.0 (`initialize`, `tools/list`, `tools/call`), streamable-http без SSE. Подключай Claude Desktop / Cursor / свой скрипт — они видят ту же библиотеку, что и друзья в комнате. |

Инструменты: `library_search` (запрос, тип), `library_get` (объект + свойства + пометки + связи + где всплывал),
`library_create` (тип, заголовок, свойства, тело), `library_update` (свойства, тело, архив), `library_append` (дописать
в тело под заголовком, не стирая), `file_read` (текст вложения кусками), `web_search`, `web_fetch`, `lookup`, `weather_now`,
`calendar_upcoming`, `feed_fetch`, `github_activity`, `library_link`
(`belongs_to` / `about` / `blocks` / `assigned_to` / `contradicts` / `related`…), `library_note`, `library_types`
(схемы всех типов), `contracts_list` (слово игрока), `room_status` (кто жив, отношения, когда игрок был).
Список с JSON-схемами — `GET /api/tools`.

Каждому агенту в system prompt попадает короткий «ГДЕ ТЫ»-бриф (комната, библиотека, игрок, Режиссёр) и
правило: инструменты — это руки, пользоваться ими по делу и в характере, а не отчитываться о них.

```bash
# внешний MCP-клиент (с другой машины нужен MCP_TOKEN)
curl -s http://localhost:3000/mcp -H 'content-type: application/json' \
  -H 'authorization: Bearer $MCP_TOKEN' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"library_search","arguments":{"query":"осциллограф"}}}'
```

Claude Desktop (`claude_desktop_config.json`): `{"mcpServers":{"triad":{"url":"http://localhost:3000/mcp"}}}` —
через `mcp-remote`, если клиент умеет только stdio.

## Холст и сцена

- **Холст** (центр, React Flow): узлы-карточки с заголовком, телом в markdown, типом (концепт / задача / конфликт /
  инсайт) и автором (цвет). Таскать, зумить, связывать перетаскиванием за точку, двойной клик — новая заметка,
  поиск и фильтр по автору, экспорт всей доски в `.md`. Позиции сохраняются; закреплённые узлы не двигаются.
- **Карточка узла** (клик): тело (редактирование / предпросмотр), **пометки всех троих** — каждый агент оставляет
  на узле запись своим голосом (`<note node="…">` в его реплике), это его память об идее; свои пометки; связи;
  кнопки **обсудить / развить / оспорить** и вопрос про узел — триада отвечает именно о нём.
- **Сцена** (справа, сворачивается): три лица со строкой состояния вместо цифр (цифры — в профиле по клику:
  HP, дофамин, уважение, цель, дневник, отношения, последние мысли), адресные реплики («Софья → Кэп», ход:
  уступка / перебивка / молчание…), чипы узлов в репликах, вкладки «Слово» и «Режиссёр».
- Режиссёр ставит каждый раунд как **сцену из 1–4 битов** (кто → кому, ход, намерение, подача); второй бит видит
  первый. Агентам запрещено повторять свои прошлые формулировки (они получают список «ты уже говорил»),
  обязательного вопроса в конце больше нет, говорящие ротируются, о статах они не знают — чувствуют.

## Механики комнаты

| Механика | Как работает |
|---|---|
| **HP / дофамин / уважение** | Режиссёр оценивает, «покормил» ли ты профиль каждого агента; автономные тики жгут HP (энтропия). HP = 0 → permadeath: агент произносит последние слова и замолкает до `Новая комната`. |
| **Скрытые повестки** | Каждый ход LLM-Режиссёр выдумывает агентам новые психологические цели; видно в инспекторе и по кнопке «цели». |
| **Слово игрока (контракты)** | Пишешь «обещаю / сделаю до пятницы» — Режиссёр оформляет контракт с дедлайном, назначает **поручителя**, который ставит на тебя свои HP (10–30). Сдержал (отчитался в чат или ✓ во вкладке «Слово») — поручитель получает HP, все +уважение. Нарушил или вышел срок — поручитель теряет ставку, комната теряет к тебе уважение; поручитель может от этого умереть. Вкладка «Слово»: таймеры, ✓ / 💀 / ✖, форма «дать слово». |
| **Отношения агентов** | Матрица симпатий −100..100 по парам; Режиссёр двигает её каждый ход (поддержал → +, высмеял → −, сговор против игрока → + друг к другу). Агенты видят «ты в контрах с Софьей (−45)». Треугольник — в инспекторе Режиссёра. |
| **Долговременная память** | У каждого агента свой дневник от первого лица. После каждых `MEMORY_EVERY` (8) новых сообщений быстрая модель фоново переписывает его: мнение об игроке, его обещания, обиды на соседей, незакрытые споры. Дневник подмешивается в промпты агента и Режиссёра — ничего не забывается при прокрутке окна контекста. |
| **Лента событий** | Все механические факты (контракт создан/сдержан/нарушен, смерть) код пишет в `room_events`; Режиссёр обязан их отыграть на ближайшем ходу (поручитель реагирует первым). |
| **Доска** | Режиссёр извлекает из каждой реплики 0–3 узла с телом и связи; новые узлы раскладываются рядом с соседями; агенты пишут пометки прямо в узлы. |

## Субагентный пайплайн («мозг» по умолчанию)

Один большой запрос Режиссёра разложен на маленькие, чтобы каждую работу могла сделать даже слабая/бесплатная модель,
а сильная — сделать лучше (`DIRECTOR_MODE=pipeline`, `AGENT_MODE=pipeline`):

```
реплика игрока
  → Reader        что сказал игрок: тема, намерение, обещания (→ контракты), кого «покормил», какие узлы задел
  → Caster        сцена: 1–3 бита (кто → кому, ход, намерение, подача) + скрытая цель каждому говорящему
  → для каждого бита: Think (мысль + «цепляюсь за фразу») → Speak (реплика) → Note (пометка на узле, если о нём речь)
  → после речи, параллельно:
      Archivist     типизированные объекты, свойства, связи, упоминания (библиотека)
      Psychologist  состояния, цели на следующий раунд, статы, отношения
```

У каждой стадии есть детерминированный дефолт: упавший Reader не отменяет сцену, молчащий Психолог заменяется
оценкой «кормления» из Reader и т.д. Тайминги стадий видны во вкладке «Режиссёр». Старый монолитный режим —
`DIRECTOR_MODE=single` / `AGENT_MODE=single` (один вызов с prefill `<ego_thought>`).

Селектор моделей в ⚙ берёт каталог OpenRouter (`GET /api/models`), бесплатные первыми; для бесплатных помни про
лимиты запросов — в режиме субагентов на раунд уходит 6–10 вызовов.

## Пайплайн хода (режим single)

1. **`POST /api/chat`** сохраняет реплику игрока →
2. **`director.rs`** собирает контекст (агенты, состояния, повестки, доска, дневники, отношения, события, кто говорил
   недавно) и зовёт LLM в JSON-режиме. Ответ (`scene`, `inner_states`, `updated_agendas`, `stat_deltas`,
   `graph_mutations`, `node_updates`, контракты, отношения) парсится
   устойчиво: ```json-обёртки, мусор вокруг, висячие запятые. Если модель не ответила — fallback-план
   (случайный говорящий, повестки с прошлого хода), комната не падает.
3. Повестки записываются в `agents.current_agenda`, дельты клампятся (HP 0..100, уважение −100..100),
   узлы/рёбра санитизируются (`mermaid::safe_id`, `sanitize_label`) и попадают в SQLite.
4. **`agent_runner.rs`** для каждого бита сцены строит system prompt (состояние прозой, цель, соседи и отношения,
   доска и фокус-узел, дневник, «ты уже говорил», уже сказанное в этом раунде, сам бит: кому / ход / намерение / подача)
   и отправляет запрос с **prefill `<ego_thought>`** и штрафами за повторы. Ответ режется на мысль, речь и
   `<note>`-пометки к узлам. Биты идут последовательно — каждый видит предыдущие.
5. Всё это стримится в UI через SSE (`/api/events`): статус Режиссёра, реплики по мере появления, обновления графа.

`POST /api/tick` — тот же раунд без реплики игрока (Режиссёру явно сказано сталкивать агентов между собой) плюс
энтропия: все живые теряют HP/дофамин. HP = 0 → **permadeath**, агент замолкает навсегда (до `POST /api/reset`).

`POST /api/schema` — Триада собирает структурированную Mermaid-схему текущей темы с аннотациями каждого.

## Telegram Mini App

Когда задан `TELEGRAM_BOT_TOKEN`, сервер переходит в **публичный режим**:

- каждый запрос из мини-аппа несёт подписанный Telegram `initData` (`Authorization: tma …`); сервер проверяет HMAC
  по токену бота и свежесть (24 ч) — подделать пользователя нельзя;
- у каждого Telegram-пользователя **своя комната** — отдельный SQLite `~/.triad/rooms/tg_<id>.db` со своими агентами,
  контрактами, дневниками. Твоя старая база живёт в комнате `local` и открывается только с localhost;
- браузер без Telegram снаружи получает экран «Открыть в Telegram» (401 `telegram_required`); для отладки можно
  разрешить `ALLOW_ANON_ROOMS=true`;
- бот сам отвечает на `/start` кнопкой «⚡ Открыть комнату» (long polling, вебхуки и сертификаты не нужны);
- ключ и модели из мини-аппа может менять только `TELEGRAM_ADMIN_IDS` (твой user id).

### За 15 минут с ноутбука (без VPS)

1. **@BotFather** → `/newbot` → получи токен. Там же: `/mybots` → бот → *Bot Settings* → *Menu Button* — пока пропусти, URL появится на шаге 3.
2. **Туннель** до локального сервера (нужен https): [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)
   ```bash
   cloudflared tunnel --url http://localhost:3000
   ```
   В выводе будет `https://<что-то>.trycloudflare.com` — это и есть адрес мини-аппа (меняется при каждом запуске туннеля).
3. **Настрой triad**:
   ```bash
   triad setup      # ключ OpenRouter → токен бота → WEBAPP_URL=https://<что-то>.trycloudflare.com → свой user id
   triad
   ```
   или вручную в `~/.triad/config.env`: `TELEGRAM_BOT_TOKEN=…`, `WEBAPP_URL=https://…`, `TELEGRAM_ADMIN_IDS=…`.
4. В **@BotFather**: *Menu Button* → вставь тот же https-URL (или `/newapp` — даст прямую ссылку `t.me/<bot>/<app>`).
5. Открой бота в Telegram → `/start` → кнопка. Готово: комната в телефоне, десктоп по-прежнему на http://localhost:3000.

### На VPS (постоянно)

```bash
ssh user@vps 'curl -fsSL https://raw.githubusercontent.com/BreezeAreaSay/AIPLACE/main/install.sh | TRIAD_NO_SETUP=1 sh'
ssh user@vps '~/.triad/bin/triad setup'     # ключ, токен бота, WEBAPP_URL=https://triad.example.com, admin id
```

`/etc/systemd/system/triad.service`:

```ini
[Service]
ExecStart=/home/user/.triad/bin/triad --no-prompt --host 127.0.0.1 --port 3000
Restart=always
User=user
[Install]
WantedBy=multi-user.target
```

Сверху Caddy: `triad.example.com { reverse_proxy 127.0.0.1:3000 }` — TLS он получит сам. Обновление:
`triad update && systemctl restart triad`. Если фронт хостится отдельно (Vercel/Pages) — задай `VITE_API_URL=https://api.…` при сборке; CORS permissive.
